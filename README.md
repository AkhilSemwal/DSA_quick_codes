# Data Structures and Algorithms in C

This repository contains implementations of fundamental Data Structures and Algorithms in C. It is intended for students, beginners, and anyone looking to strengthen their understanding of DSA concepts through clean and well-organized code.

## Topics Covered or Will be covered
- Arrays
- Strings
- Linked Lists
- Stacks
- Queues
- Trees
- Heaps
- Searching Algorithms
- Sorting Algorithms
- Recursion
- Hashing
- Graphs (if added)
