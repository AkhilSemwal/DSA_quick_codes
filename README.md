# 🧠 DSA Quick Codes

This repository is built for **students, beginners, and anyone practicing DSA** who wants quick, understandable implementations rather than overly complex code.

## ▶️ Running the Programs

Clone the repository:

```bash
git clone https://github.com/AkhilSemwal/DSA_quick_codes.git
```

Navigate into the repository:

```bash
cd DSA_quick_codes
```

Compile a C program using GCC:

```bash
gcc filename.c -o output
```

Run it:

### Windows

```bash
output.exe
```

### Linux / macOS

```bash
./output
```
